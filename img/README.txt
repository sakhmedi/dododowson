Put image files here, then reference them in ../content.js

Suggested sizes:
  album covers  — square 1:1, ~1000x1000px      -> cover:  "img/album1.jpg"
  video posters — 16:9 (optional; else pulled from YouTube)
  press photo   — portrait 4:5                   -> photo:  "img/press.jpg"
  og.jpg        — 1200x630px, for social sharing -> used automatically

If an image is missing, the site shows an elegant placeholder tile instead.
